# Dig Legends

A relaxed Roblox treasure-digging collection game: dig up fossils, gems and relics, sell them,
buy better shovels, unlock new zones and fill your collection book. Built on the Reel Legends
code base.

Status: step 1 of 6 (setup). The game still plays like Reel Legends until step 2 swaps
fishing for digging. See the build plan doc in the project for the full roadmap.

Build the place file with `python3 tools/build_place.py`, then open `build/DigLegends.rbxlx`
in Roblox Studio. All shop ids are 0 ("Coming soon") until the passes and products are created.
